思路分析

感觉是很经典的一道题目，但是之前就是没遇到过。

首先，不难把题意转化成有 $n$ 个数字 $a$，构造序列 $b$，满足 $b_i\in\set{1,-1}$，且 $\operatorname{abs}(\sum_{i=1}^na_ib_i)$ 尽可能小。

一个非常简单的想法是使用 $dp_{p,i}$ 表示在前 $p$ 个数字能不能取到 $i$。显然是一个 $O(\frac{n^2V}{\omega})$ 的算法，应该是过不去的。

我们考虑怎么优化。目前的主要问题是我们的状态是 $01$，一般来说不是特别优秀，我们希望能够往值里面塞一点更有用的信息。

我们可以记 $V=5000$，由于 $a_i\in[1,V]$，因此，显然我总是有一种重新排列求和顺序的方法，满足上面的求和的式子在任意一步都是在 $[-V,V]$ 的范围内的。

虽然这仍然不好做，但是这到也给了我们一点启示：我有没有可能强制让他在每一步都必须在这个范围内？

我们考虑把这个问题转化成 01 背包。一种非常自然的想法是把问题变成所有数字都加，然后选一些数字减去他们的两倍，使得最终的结果的绝对值最小。

令 $sum=\sum_{i=1}^na_i$，则我选出来的数字的和肯定在 $[\frac{sum}{2}-V,\frac{sum}{2}+V]$ 之间。

于是我们有了这样一个想法：我能不能先取一段尽可能接近 $\frac{sum}{2}$ 的前缀，并且认为我们选了这一段，随后再进行调整？

这么做似乎是有一定的道理的：调整一个数字的代价是明确的，而且每一个数字都只有调整或者不调整两种选择。

最重要的是，我调整左边的就是在减，调整右边的就是在增，没有任何顺序限制或者必须选的限制，这非常有利于我们解决这个问题。

于是我们考虑设计出这样的一个状态：$dp_{v,l,r}$，表示我已经决定了在 $[l,r]$ 范围内的数值要不要调整，此时能否得到 $v$。显然转移方向仍然是 $l$ 扩展或者 $r$ 扩展。

不过不难注意到这仍然是一个 $\frac{n^2V}{w}$ 的思路，但是这个状态设计的优化方向是明确的：

$v$ 绝对没法优化掉，因为一对 $(l,r)$ 固然对应了多个完全没有规律的 $v$，因此我们只能考虑优化掉 $l,r$。

此时我们不妨考虑优化 $l$，那么对于固定的 $r,v$，$l$ 有什么特性呢？非常显然：如果 $dp_{v,l,r}$ 为 $1$，则 $dp_{v,l-\Delta,r}$ 全部都是 $1$，也就是说可以认为 $dp_{v,l,r}$ 在 $(v,r)$ 固定的时候是有单调性的，总是存在一个 $l_0$ 满足 $dp_{v,l,r}=[l\le l_0]$。

至此，豁然开朗，我设计状态为 $dp_{v,r}$ 表示存在调整 $[l,r]$ 区间内的状态可以取到 $v$ 的最大的 $l$。转移仍然是显然的，不过看起来仍然是一个 $n^2V$ 的复杂度。

只需要再注意到一点：只有当 $l\ge dp_{v,r-1}$ 的时候才有必要进行 $l\to dp_{v,r}$ 的转移，不然的话 $dp_{v,r-1}\to dp_{v,r}$ 的转移会把这个贡献统计进去。

因此对于固定的 $v$，所有的 $r$ 对应的 $l$ 的枚举量只有 $O(n)$，因此总时间复杂度可以做到 $O(nV)$。

参考代码如下：

CPP 
#include<bits/stdc++.h>
using namespace std;
int n,a[10005],dp[2][10005],sm,cs,cp,ans;
signed main(){
	ios::sync_with_stdio(0); cin>>n; ans=5000;
	for(int i=1;i<=n;++i) cin>>a[i],sm+=a[i];
	sort(a+1,a+n+1,greater<int>());
	for(int i=1;i<=n;++i)
		if(cs+a[i]>sm/2){
			cp=i-1; break;
		}
		else cs+=a[i];
	dp[cp&1][5000-sm/2+cs]=cp+1;
	for(int i=cp+1;i<=n;++i){
		memcpy(dp[i&1],dp[i-1&1],sizeof dp[0]);
		for(int j=0;j+a[i]<=10000;++j)
			dp[i&1][j+a[i]]=max(dp[i&1][j+a[i]],dp[i-1&1][j]);
		for(int j=10000;j>=0;--j)
			for(int k=max(dp[i-1&1][j],1);k<dp[i&1][j];++k)
				if(j>=a[k]) dp[i&1][j-a[k]]=max(dp[i&1][j-a[k]],k);
	}
	for(int j=0;j<=10000;++j) if(dp[n&1][j])
		ans=min(ans,abs(sm-2*(sm/2-5000+j)));
	cout<<ans<<endl;
}
