思路分析

询问两点之间的答案是一个经典问题，相信大家都会做，我们来简单回顾一下解法：

我们钦定图是连通的。

于是我们随便找出来整张图的任意一个生成树，就能够找到两点间的一条合法路径。但是我们要求解的是所有路径的最小值。

一种想法是我找出来整张图中的所有的环，将其插入到线性基中。这是因为最终实际走的路径一定是某一条路径异或上有差异的部分得到的。

然而这显然是不行的。不过我们考虑到这样的一个性质：任意一个环都可以通过若干简单环通过对称差操作得到。

因此我们只需要找出所有的简单环插入到线性基中，查询的时候就是将两个点在生成树上的路径的异或值和线性基中的元素进行异或的最小值。

现在来看我们的问题。我们问的是 $\sum_{i,j}f(v_i\oplus v_j)$，其中 $f(x)$ 表示 $x$ 线性基中的元素进行异或的最小值。这看起来非常棘手。

实际上，我们可以证明 $f(a\oplus b)=f(a)\oplus f(b)$！

具体来说，我们考察 $f$ 的实际操作：

从高到低枚举每一位 $d$，如果 $x$ 这 $d$ 一位是 $1$，那么将其异或上这一位的基 $b_d$。

对比 $f(a\oplus b)$ 的操作过程和 $f(a)\oplus f(b)$ 的过程：

若在 $d$ 位，$a=b=1$，则 $f(a)\oplus b_d\to f(a),f(b)\oplus b_d\to f(b)$，即 $f(a)\oplus f(b)\oplus b_d\oplus b_d=f(a)\oplus f(b)\to f(a)\oplus f(b)$，都是完全不变化的。

若在 $d$ 位，$a=b=0$，都是完全不变化的。

若在 $d$ 位，$a=1,b=0$（$a=0,b=1$ 是完全对称的），则 $f(a)\oplus b_d\to f(a)$，即 $f(a)\oplus f(b)\oplus b_d\\to f(a)\oplus f(b)$，但是同时 $f(a\oplus b)\oplus b_d\to f(a\oplus b)$，于是仍然相等。

显然在没有操作任何一位的时候有 $f(a\oplus b)=f(a)\oplus f(b)$，则按照相同顺序操作每一位的过程中，两边仍然保持一致。

于是我们可以把每一个位置直接重新标记成 $a_i=f(v_i)$，然后计算 $\sum_{i,j}a_i\oplus a_j$，这显然是简单的，直接按位统计贡献即可。

于是此题可解，时间复杂度 $O(n\log V)$，参考代码如下：

CPP 
#include <bits/stdc++.h>
using namespace std;
#define int long long
constexpr int mod=998244353;
int n,m,d[200005],c1[30],ans; bool vis[200005];
struct node{
	int p,v; node(int p=0,int v=0):p(p),v(v){}
}; vector<node>son[200005];
struct liner_base{
	int v[30];
	inline void reset(){ memset(v,0,sizeof v); }
	inline void ins(int a){
		for(int i=29;i>=0;i--)
			if(a>>i&1)
				if(v[i]) a^=v[i];
				else return void(v[i]=a);
	}
	inline int camin(int a){
		for(int i=29;i>=0;i--)
			if(a>>i&1) a^=v[i];
		return a;
	}
}lib;
vector<int>bat;
inline void dfs(int p){
	vis[p]=1; bat.emplace_back(p);
	for(const auto&sp:son[p])
		if(vis[sp.p]) lib.ins(sp.v^d[p]^d[sp.p]);
		else d[sp.p]=d[p]^sp.v,dfs(sp.p);
}
signed main(){
	ios::sync_with_stdio(0); cin>>n>>m;
	for(int i=1,l,r,v;i<=m;++i)
		cin>>l>>r>>v,
		son[l].emplace_back(r,v),
		son[r].emplace_back(l,v);
	for(int i=1;i<=n;++i) if(!vis[i]){
		bat.clear(); lib.reset(); dfs(i);
		for(int j:bat) d[j]=lib.camin(d[j]);
		for(int j:bat)
			for(int k=0;k!=30;++k)
				c1[k]+=d[j]&1,d[j]>>=1;
		for(int k=0;k!=30;++k)
			ans=(ans+(c1[k]*(bat.size()-c1[k])%mod<<k))%mod;
		memset(c1,0,sizeof c1);
	}
	cout<<ans*2%mod<<endl;
}
