思路分析

树上区间 DP 的练习题。

套路的，对于序列问题上树，我们把问题拽回序列上，考虑能不能做出来比较优秀的解法。

考虑设计 $dp_{i,j,k}$ 表示我们决定要覆盖 $(i,j)$，并且目前准备决策第 $k$ 个数字的情况下的最优解。

当我处在 $dp_{i,j,k}$ 的时候，我有几种可能的决策：

  1. 放弃这一次的贡献，前提是我区间内有足够的次数可以给我放弃；
  2. 向左扩展到 $dp_{i-1,j,k}$，额外贡献 $a_k$，没有任何限制；
  3. 向右扩展到 $dp_{i,j+1,k}$，额外贡献 $a_k$，没有任何限制。

于是做完了，时间复杂度显然是 $O(n^3)$ 的，现在该考虑上树了。

区间 DP 上树肯定就是直接使用树上区间 DP 了。具体来说，令 $dp_{i,j,k}$ 表示的是我决定要覆盖树上的 $(i,j)$ 的链，不包含 $i,j$ 两点，并且目前准备决策第 $k$ 个数字的情况下的最优解。

当我处在 $dp_{i,j,k}$ 的时候，决策和上面是类似的，只不过扩展变成了走所有连着的子结点（注意不能缩短链）。显然这么做时间复杂度没有一点变化，仍然是 $O(n^3)$ 的。

于是此题可解，注意需要给每一个点挂一个虚点（不然无法选中叶子节点）并特判 $n=1$ 的情况。参考代码如下：

CPP 
#include<bits/stdc++.h>
using namespace std;
#define int long long
int t,n,a[155],dp[305][305],np[305][305],sz[155][155],ans;
vector<int>son[305]; int mx[305][305],d[155][155],f[155][155];
inline void dfs(int p,int d,int f,int rt){
	::f[rt][p]=f; sz[rt][p]=1; ::d[rt][p]=d;
	for(int sp:son[p]) if(sp!=f)
		dfs(sp,d+1,p,rt),sz[rt][p]+=sz[rt][sp];
}
inline int id(int p){return p>n?p-n:p;}
signed main(){
	ios::sync_with_stdio(0);
	for(cin>>t;t;t--){
		cin>>n; n++;
		for(int i=1;i<=n;++i) son[i].clear();
		for(int i=1;i!=n;++i) cin>>a[i];
		for(int i=1,l,r;i!=n;++i)
			cin>>l>>r,
			son[l].emplace_back(r),
			son[r].emplace_back(l);
		if(n==2){ cout<<a[1]<<endl; continue; }
		for(int i=1;i<=n;++i) dfs(i,0,0,i);
		for(int i=1;i<=n*2;++i)
			for(int j=1;j<=n*2;++j)
				dp[i][j]=-1e18;
		for(int i=1;i<=n*2;++i)
			for(int j=1;j<=n*2;++j)
				if(d[id(i)][id(j)]>1){
					dp[i][j]=0; mx[i][j]=n-1;
					if(i<=n) mx[i][j]-=sz[id(j)][i];
					if(j<=n) mx[i][j]-=sz[id(i)][j];
				}
		for(int c=1;c<=n;++c){
			for(int i=1;i<=n*2;++i)
				for(int j=1;j<=n*2;++j)
					np[i][j]=-1e18,ans=max(ans,dp[i][j]);
			for(int i=1;i<=n*2;++i)
				for(int j=1;j<=n*2;++j){
					if(c<=mx[i][j]) np[i][j]=max(np[i][j],dp[i][j]);
					if(i<=n){
						np[i+n][j]=max(np[i+n][j],dp[i][j]+a[c]);
						for(int sp:son[i]) if(sp!=f[id(j)][i])
							np[sp][j]=max(np[sp][j],dp[i][j]+a[c]);
					}
					if(j<=n){
						np[i][j+n]=max(np[i][j+n],dp[i][j]+a[c]);
						for(int sp:son[j]) if(sp!=f[id(i)][j])
							np[i][sp]=max(np[i][sp],dp[i][j]+a[c]);
					}
				}
			for(int i=1;i<=n*2;++i)
				for(int j=1;j<=n*2;++j)
					dp[i][j]=np[i][j];
		}
		cout<<ans<<endl; ans=0;
	}
}
