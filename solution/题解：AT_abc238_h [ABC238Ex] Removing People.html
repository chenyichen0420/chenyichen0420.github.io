思路分析

看数据范围，大致猜一个三次方，不过具体怎么做？

直觉上应该会是一个 DP 题，但是不太确定具体怎么 DP，于是我们考虑区尝试刻画一个合适的 DP 状态。

我们发现如果直接按照原始的流程去做的话，每一步都依赖于前面的所有步，你总是需要把所有的人的生死状态记录下来，非常不优秀。

我们考虑正难则反，倒着考虑整个过程。

容易注意到我们此时的操作就是最后任意保留下来一个人，然后每一次沿着某一个活着的人的方向复活一个人，代价就是二者的距离。

于是我们注意到一个非常美妙的性质：因为我和我复活的人中间是不能有别的人的，所以说我新复活的人会将我的方向上的这个区间砍成两个独立的部分。

于是我们对这个东西进行区间 DP 即可。

具体来说，我们先断环为链，随后考虑令 $dp_{i,j}$ 表示保留了 $i,j$ 这两个点的情况下，内部的人全部复活的所有情况的代价之和。考虑转移。

注意到我们求的是所有的情况的代价之和，所以经过推导，我们还需要一个辅助的数值 $c_{i,j}$，表示保留了 $i,j$ 这两个点的情况下，内部的人全部复活的情况数。

详细描述一下 $dp$ 的转移。我们假设我们现在想要求出 $dp_{i,j}$ 的数值。此时我们钦定了我们 已经保留了 $i,j$ 两个点。

那么如果 $s_i=R$，我们就可以让 $i$ 来复活人。假设我们复活的人是 $k$，那么对 $dp_{i,j}$ 的贡献有三部分：$dp_{i,k}\times c_{k,j}\times\binom{(j-k-1)}{(k-i-1)+(j-k-1)}$，$c_{i,k}\times dp_{k,j}\times\binom{(j-k-1)}{(k-i-1)+(j-k-1)}$，和 $(k-i)\times c_{i,k}\times c_{k,j}\times\binom{(j-k-1)}{(k-i-1)+(j-k-1)}$。

前两部分是将左右子区间的贡献传上来。以左子区间为例，首先左子区间的每一种决策都能和右子区间的所有决策组合，所以首先乘上一个 $c_{k,j}$。再考虑到两个区间内部的顺序其实是任意的，所以我们还需要在两边的大小之和个位置中选出左区间的大小个位置留给左边，也就是 $\binom{(j-k-1)}{(k-i-1)+(j-k-1)}$。

最后一部分是 $i$ 复活 $k$ 的贡献，意思是我复活产生的 $(k-i)$ 会贡献剩下两个区间的总决策数量次。类似前面我们可以推得这个决策数量就是内部决策数量之积再乘上二者的相对顺序的系数。

如果 $s_j=L$，那么会产生一组非常相似的贡献，留给读者自行推导。

最后转移一下 $c$，显然 $c_{i,j}$ 就是所有的 $(i,k),(k,j)$ 的总贡献的转移，形式上就是只保留前面 $dp$ 转移的第三项中的转移系数，不再赘述。

边界条件：$dp_{i,i+1}=0,c_{i,i+1}=1$。至此，此题可解，时间复杂度 $O(n^3)$，参考代码如下：

CPP 
#include<bits/stdc++.h>
using namespace std;
#define int long long
constexpr int mod=998244353;
int n,dp[605][605],ans,c[605][605];
char s[605]; int jc[605],ny[605];
inline int qpow(int a,int b){
	int ret=1;
	for(;b;b>>=1,a=a*a%mod)
		(b&1)&&(ret=ret*a%mod);
	return ret;
}
inline int cvc(int n,int m){
	return jc[n+m]*ny[n]%mod*ny[m]%mod;
}
signed main(){
	ios::sync_with_stdio(0); cin>>n;
	for(int i=1;i<=n;++i) cin>>s[i],s[i+n]=s[i];
	for(int i=1;i!=n*2;++i) c[i][i+1]=1;
	for(int i=jc[0]=1;i<=n*2;++i) jc[i]=jc[i-1]*i%mod;
	ny[n*2]=qpow(jc[n*2],mod-2);
	for(int i=n*2;i>=1;i--) ny[i-1]=ny[i]*i%mod;
	for(int l=2;l<=n;++l)
#define j (i+l)
		for(int i=1;j<=n*2;++i){
			if(s[i]=='R')
				for(int k=i+1;k!=j;++k)
					c[i][j]=(c[i][j]+c[i][k]*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+c[i][k]*dp[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+dp[i][k]*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+(k-i)*c[i][k]%mod*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod;
			if(s[j]=='L')
				for(int k=i+1;k!=j;++k)
					c[i][j]=(c[i][j]+c[i][k]*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+c[i][k]*dp[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+dp[i][k]*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod,
					dp[i][j]=(dp[i][j]+(j-k)*c[i][k]%mod*c[k][j]%mod*cvc(k-i-1,j-k-1))%mod;
		}
	for(int i=1;i<=n;++i) ans=(ans+dp[i][i+n])%mod,cerr<<dp[i][i+n]<<" ";
	cerr<<ans<<endl; cout<<ans*ny[n]%mod<<endl;
}
