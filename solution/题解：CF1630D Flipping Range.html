思路分析

喵喵题。

首先，由裴蜀定理可知，如果我有 $a,b$ 两种可行的操作，那么我一定可以组合出长度为 $\gcd(a,b)$ 的操作。这是由于 $a,b\le\lfloor\frac{n}{2}\rfloor$，所以我总数可以在目标操作区间的左边或者右边找到一块足够大的空地来进行操作。

于是问题变成了我有一个序列 $a$，我可以任意的将其中的长度为 $b$ 的子段取反，问最终能做到的和最大是多少。

非常显然，由于我可以将长度为 $b$ 的子段取反，因此我可以错一个位置执行操作，也就是将 $i$ 和 $i+b$ 位置同时取反。

因此，我们将所有的元素按照其下标 $\bmod b$ 的值进行分类，则同一类内的元素我可以任意选择两个直接取反。

显然如果一个类内有偶数个负值，则两两操作一下就都变成正的了。如果有奇数个负值，则两两操作一下，可以让绝对值最小的那个是负的，别的都是正的。

最后考虑一下单独进行一次长度为 $b$ 的翻转的效果：显然就是所有的类内负值的个数的奇偶性变一下。

至此答案呼之欲出：我们计算所有的位置的绝对值之和 $ans$，计算有奇数个负值的类内的绝对值最小元素的绝对值之和 $ans1$，计算有偶数个负值的类内的绝对值最小元素的绝对值之和 $ans2$，答案就是 $ans-2\times\min(ans1,ans2)$。

参考代码如下：

CPP 
#include<bits/stdc++.h>
using namespace std;
#define int long long
int t,n,m,a[1000005],b[1000005],ans,mv[1000005],cnt[1000005],av1,av2;
signed main() {
	ios::sync_with_stdio(0);
	for(cin>>t;t;t--){
		cin>>n>>m; ans=av1=av2=0;
		for(int i=1;i<=n;++i) cin>>a[i];
		for(int i=1;i<=m;++i) cin>>b[i];
		for(int i=2;i<=m;++i) b[1]=__gcd(b[1],b[i]);
		for(int i=0;i!=b[1];++i) mv[i]=1e9,cnt[i]=0;
		for(int i=1;i<=n;++i)
			ans+=abs(a[i]),cnt[i%b[1]]+=(a[i]<0),
			mv[i%b[1]]=min(mv[i%b[1]],abs(a[i]));
		for(int i=0;i!=b[1];++i)
			if(cnt[i]&1) av1+=mv[i];
			else av2+=mv[i];
		ans-=2*min(av1,av2);
		cout<<ans<<endl;
	}
}
