思路分析

感觉这个题解很不好写，容易整成一车注意到。

显然，这无法套用什么算法模板一类的，我们需要从题目本身动刀，而不是莫名其妙的提出一个解法，然后自圆其说，这只会让人非常难受。

显然这道题的关键点在于那个估价函数：上升次数 $\times10^3$，加上总能力提升值。另一个关键点在于你不知道你的初值。

第二点告诉你什么：你永远不可能通过一个决策做到抛弃一个任务。对于给出的任务列表，你唯一的选择是全盘接受。并且，这个任务列表必须保证在任何初值下你都能够到达 $n$。

此时我们思考有什么基本操作组是我们能够使用的：

  1. 不停的兜底，第 $i$ 次操作让 $i$ 这个能力值消失。显然我们直接做 $(i,1)$，将能力值为 $i$ 的情况划分到能力值为 $i+1$ 的情况去。
  2. 直接抹除一种能力值。显然操作 $(i,n-i)$ 可以将能力值为 $i$ 的变成 $n$，解决掉他。

然而很可惜，上面两种方案都不能解决掉这个问题。

第一种方案的优点是能力提升值之和非常小，但是问题在于他大量的使用了难度上升的任务，导致上升惩罚过大。

第二种方案的优点是通过逆序操作，可以完全消除上升惩罚，但是问题在于他的能力提升值之和过大。

也就是说，一路扫过去的解法必不可行。然而我们也不难发现，二者可以说是优势互补，我们肯定考虑将二者揉到一起。然而具体怎么揉呢？

深入研究二者的优势的产生原因。

第一种方案之所以能力提升值之和非常小，就是因为他每一次操作实际上把一大包不同的初始值目前的数值都提升了。于是原本 $O(n^2)$ 的总提升量被通过复用的方式压缩到了 $n$。

第二种方案之所以上升惩罚小，就是因为他把不同的包给隔离开看待了。如果两个包的合并之间没有任何依赖关系，那我就可以通过逆序来减少上升惩罚。

相信此时你已经有了一个比较好的方向了：我可不可以考虑通过第一种操作将一些初始状态先给绑到一起，然后通过第二种操作来减少绑的过程中的上升惩罚呢？

非常好的思路！然而我们还可以更进一步：这种合并结构，我一定只做两层吗？我可不可以多做几层？

显然，同一层的不同包的初始值在值域上不交，因此我们可以产生一种类似分治的想法。

不妨让我们考虑一下最熟悉的二叉，看看会怎么样：

每一层合并的时候，都是将相邻的两个位置给拍到一起。显然同一层的元素，无论怎么拍，都是独立的，我们完全可以使用第二种技巧消除上升惩罚。

然而，每一层在拍的时候，总的上升值都是 $O(n)$ 级别的，而偏偏我们又要拍 $\log$ 次，于是这个做法死掉了。

做法死掉了之后，不妨仔细思考一下：这个做法是怎么死的？我们发现，每一层的 $O(n)$ 的上升值是无法避免的，所以就是层数太多了导致的。

于是我们的优化方向也很清晰：减少层数。显然这也就意味着我们需要增加叉数。

增加叉数的时候，我们势必会面临一个新的问题：我该怎么合并这些叉？

如果局限于单组内的叉，你将很容易陷入死路：同一组内的东西，不管是用第一种，还是用第二种，都会导致某个代价非常大。

此时我们应该做的是设计结构消除主导项。既然主导项是下降惩罚，那我肯定要把尽可能多的东西解绑，然后逆序处理。

但是注意到每一层至少使用 $O(n)$ 的时间合并，于是一方面我们要限制单层用时就是 $O(n)$ 的，另一方面要限制层数为 $\frac{10^6}{n}=4$ 及以下。

既然要求单层用时为 $O(n)$，那我就势必需要使用第一种合并策略，注意使用第一种策略其实只限制了一组内的顺序不可乱，没有限制不同组不可乱。因此我们按照组间逆序为主要顺序，组内顺序为次要顺序，直接做，那么我分几叉，就只有几次上升惩罚。

考虑叉数。显然直觉上叉数应该是 $\sqrt[4]{250000}$，不过由于我们还有上升惩罚，所以非常遗憾，这个叉数是不符合要求的。

那么叉数自动调整成 $\sqrt[3]{250000}$，此时就可以通过了。需要的次数恰为 $923093$，是目前所有公开提交当中操作次数最少的解。

参考代码如下：

CPP 
#include<bits/stdc++.h>
using namespace std;
int n; vector<int>lp,np;
vector<pair<int,int>>ans;
constexpr int sz=63;
signed main(){
	ios::sync_with_stdio(0); cin>>n;
	for(int i=1;i!=n;++i) lp.emplace_back(i);
	while(lp.size()){
		do lp.emplace_back(n); while(lp.size()%sz);
		for(int i=sz;i>=2;--i)
			for(int j=lp.size()-i;j>=0;j-=sz)
				if(lp[j]!=n)ans.emplace_back(lp[j],lp[j+1]-lp[j]);
		for(int i=lp.size()-1;i>=0;i-=sz)
			np.emplace_back(lp[i]);
		swap(lp,np); np.clear();
		reverse(lp.begin(),lp.end());
		if(lp.back()==n) lp.pop_back();
	}
	cout<<ans.size()<<endl; int x=1e9,sum=0;
	for(const auto&v:ans) cout<<v.first<<" "<<v.second<<endl;
	for(const auto&v:ans){
		if(v.first<=x) sum+=v.second;
		else sum+=v.second+1000;
		x=v.first;
	}
	cerr<<sum<<endl;
}
